It snows
all over the game.

A tiny Geode mod that drops a soft snowfall over Geometry Dash. It follows you between layers, stays out of the way while you're playing, and lets you crank the particle count all the way to a whiteout.

What it does

Three settings, no menus to learn. Toggle it, tune it, forget about it.

Persistent across layers

The snowfall is parented to Geode's overlay manager, so it's created once and keeps falling as you move between the menu, level select and everything in between — no flicker on every scene change.

Optional in-level snow

By default the snow politely hides itself when a level starts and returns the moment you quit. Turn on Playlayer if you'd rather keep the blizzard going while you're attempting.

Adjustable density

Pick anything from a gentle 250-flake drift to a 3000-particle whiteout. The default of 700 is tuned to look good without touching your framerate.

Install it

The easy way takes about ten seconds. The other way is for people who like compilers.

Recommended

From the Geode index

  1. Install Geode for Geometry Dash 2.2 if you haven't already.
  2. Launch the game and open the Geode button on the main menu.
  3. Go to Download and search for Snow Particles.
  4. Hit install, then restart the game. It'll be snowing.
For developers

Build from source

Requires the Geode CLI and the GEODE_SDK environment variable pointing at your SDK checkout.

# clone the repo
git clone https://github.com/iAndyHD3/SnowParticles
cd SnowParticles

# build + install the .geode package
geode build

Prebuilt .geode files are also attached to every GitHub release.

Settings

Everything the mod exposes, straight from mod.json.

SettingTypeDefaultWhat it does
across-layers bool true Keeps one snowfall alive on the overlay layer so it carries between scenes. Requires a restart.
playlayer bool false Show snow while you're actually playing a level, instead of hiding it.
particle-count int 700 How many flakes are on screen at once. Ranges from 250 to 3000.
